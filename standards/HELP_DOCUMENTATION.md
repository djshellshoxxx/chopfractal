# Help Documentation Requirements

**Status: approved baseline.** Audio-app help and onboarding requirements are defined in [AUDIO_APP_BASELINE.md](AUDIO_APP_BASELINE.md), section 7, with the project acceptance checklist in section 10.

Help must describe shipped features accurately and remain synchronized with controls, parameter units and ranges, supported formats, and known limitations. Project-specific documentation may add detail but should not duplicate the shared baseline. Do not claim unimplemented capabilities.
