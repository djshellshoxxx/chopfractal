# Common VST Product Requirements

**Status: approved baseline.** The canonical shared feature requirements for VST-style plug-ins and standalone audio applications are maintained in [AUDIO_APP_BASELINE.md](AUDIO_APP_BASELINE.md).

Use its product profiles and per-project compliance checklist to record applicability, implementation location, verification evidence, and exceptions. Presets, state restore, Options, common controls, visualization, CPU gauge, resizing, help, MIDI/audio behavior, and release verification are specified there. Do not maintain a second copy of those requirements here.
