# ChopFractal Wiki

ChopFractal is a developing, deterministic loop-chopping and pattern-generation VST3 audio effect. You load or capture a loop, chop it, and generate rhythmic variations through a phrase, bar, beat and hit hierarchy. A fixed seed reproduces the same pattern.

This wiki is a navigation layer. The repository is authoritative: [README](../../README.md), [build status](../BUILD_STATUS.md), [modularity map](../MODULARITY_MAP.md) and the [specifications](../specs/README.md).

## Status

The source workflow and editor are incomplete. Live input capture, production GUI polish, real-host compatibility testing and release packaging are still pending. See [BUILD_STATUS](../BUILD_STATUS.md) before relying on any feature.
